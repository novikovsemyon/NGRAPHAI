# ХОВС и каталоги NGraph

## Настройка каталогов Revit

В настройках выберите виды базы элементов и базы схем. На вкладке «Параметры» укажите тип цветовой области и параметры её наименования, группы и кода. В списках доступны текстовые параметры экземпляров и типов областей текущего проекта; допустим ручной ввод имени для другого проекта. Выбранные значения используются при чтении каталогов. Типы оборудования и сигнальных точек читаются из этих же настроек.

«База данных» создаёт новый чертёжный вид, «База элементов» вставляет вариант на открытый чертёжный вид по указанной точке. В обоих окнах доступны группы, поиск, таблица вариантов и сведения об области. Отмена выбора не меняет документ. Футер включается отдельным флагом.

## Работа с ХОВС

1. На панели «ХОВС» откройте «Объекты и анализ ХОВС».
2. Создайте или выберите объект. Выбор объекта независим от открытого RVT.
3. Импортируйте XLSX. При новом формате выберите лист и разметьте колонки. Несколько колонок могут описывать один ТО или другой элемент. Для известного профиля можно принудительно вызвать разметку заново.
4. Проверьте установки и исходные значения в нижней панели. Исправьте тип и состав, снимите «Включить» у исключаемых установок.
5. Пересчитайте и проверьте кандидаты связей. Это предположения по данным, а не подтверждённые проектные решения.
6. Сохраните ревизию. Каждый раз создаётся новая запись; предыдущие ревизии не перезаписываются. Копия XLSX хранится с ревизией.
7. Для обучения выделите проверенные строки и нажмите «Обучить на исправлениях». Учитываются только изменённые непустые поля. Отсутствие компонента обозначайте словом «нет».

Без положительного расхода установки L запись не подтверждается, даже после обучения. Расчётный/скорректированный L может заменить отсутствующий основной L; наружный и рециркуляционный расходы его не заменяют. Противодымные системы, кондиционеры, увлажнители, ВТЗ и АВО не участвуют как пары приток/вытяжка.

## База и обучение

В «Настройки → Файлы» выбирается папка ХОВС. Она содержит `Projects` (объекты, ревизии и XLSX), XML-профили колонок, TSV-примеры обучения и журналы импорта. Для переноса закройте окна и скопируйте всю папку. На втором ПК укажите её в настройках. Данные базы не записываются в RVT; исходный путь Excel не требуется после сохранения ревизии.

Обучение локальное, по экспертным исправлениям и совпадениям признаков. Это не облачный AI и не заново обученная нейросеть. Обычное сохранение ревизии не обучает распознавание. Общие обучающие примеры действуют на последующие импорты в выбранной папке базы; исправления ревизии хранятся отдельно.

## Код и происхождение

Модуль `NGraph.Hovs` основан на исходниках предоставленного архива `NGrapfAI_2.0.37_Source.zip`: ExcelImporter, HovsSchema, HovsSchemaAnalyzer/ProfileStore, InstallationLearning, InstallationTypeClassifier, HeatExchangerParser, NotesEquipmentParser, SourceCellCodec, ConnectionRules. Код адаптирован к отдельной библиотеке netstandard2.0 без зависимости от Revit/WPF. Интерактивный выбор схемы передаётся в импортёр функцией; тесты используют явную разметку.

- `HovsRepository`: внешняя файловая база; ревизия появляется после полной записи временного каталога.
- `HovsWorkspaceWindow`: UI, фоновые файловые операции и явное обучение выбранных исправлений.
- `DatabaseCatalog`: вход для обеих команд каталога; транзакция выполняется после подтверждения.
- `UserSettings`: имена видов, параметры каталогов и путь ХОВС.
- `DialogTheme` и `DialogStyles.xaml`: общий стиль всех WPF-окон.

Перенесён анализатор и его разметка, не весь интерфейс компоновки/кабельного журнала 2.0.37. Построение схем в Revit выполняется существующими командами каталога; автоматическое назначение всем установкам ХОВС готовых схем не включено в этот перенос.

## Проверка

`dotnet run --project tests/NGraph.Hovs.Tests -c Release` проверяет XLSX с несколькими листами, положительный/резервный/нулевой L, обучение, ограничения связей, сохранность старых ревизий и независимость от исходного пути XLSX. `NGraph.Settings.Tests` проверяет сохранение настроек, в том числе параметров каталога. GitHub Actions выполняет тесты и сборки Revit 2021–2027.

Для интерактивной проверки: отмена обоих каталогов; пустая база; поиск и группы; вставка и Undo; нестандартные параметры областей; импорт/повторная разметка; исключение строки без L; обучение одного изменённого поля; повторное открытие ревизии; перенос папки; масштаб Windows 125–150%.
