# Обновление ХОВС, настроек и справки

- ПКМ по объектам: переименование, сравнение и удаление; по ревизиям: открытие, сравнение и удаление. Удаление требует подтверждения; история другого объекта и общее обучение сохраняются.
- Сравнение по аналогии 2.0.37: выбор двух и более ревизий, поиск, фильтр изменений, цветовые статусы, столбец «было → стало». Учитываются промежуточные изменения и сохранённые исправления; новое обучение не переписывает историю.
- Компактные окна ХОВС, разметки и сравнения; общие цвета; сворачиваемая панель исходных данных и отдельная иконка.
- Вид `!_000_NGraph_БАЗА_ОБОРУДОВАНИЯ` не служил источником данных. Удалены настройка и лишняя проверка в старой команде спецификации. `EquipmentType` сохранён как «Типоразмер оборудования для ФСА»: его использует `AlgoritmCreateFootorWithEquipment`.
- Стандартные INI: `%APPDATA%\NGraph\Settings`. Четыре оригинальных UTF-16 файла поставляются с модулем; SingleUser MSI размещает личную копию при установке. Для MultiUser личная папка создаётся при первом запуске каждого пользователя. Изменённые INI сохраняются; старые стандартные соответствия переносятся один раз. Произвольные пользовательские пути не заменяются.
- `settings.ini` теперь задаёт шаг округления кабеля в метрах. Значение проверяется до изменения модели.
- Справка: поиск по всем 19 командам, фактическая версия загруженного модуля, встроенный PDF. Ссылка на исходный код удалена.

## Сборка документации

Текст окна и PDF: `NGraph/Resources/Help/Commands.xml`. Генерация: `python tools/build_manual.py` (Python 3, ReportLab, DejaVu Sans; для своего каталога шрифтов задайте `NGRAPH_FONT_DIR`). Генератор проверяет, что все команды ленты документированы. PDF включён в DLL как ресурс и доступен кнопкой «Открыть PDF».

## Проверки

- `dotnet run --project tests/NGraph.Settings.Tests -c Release`: сохранение настроек, миграция/сохранение INI, версия, чтение округления.
- `dotnet run --project tests/NGraph.Hovs.Tests -c Release`: XLSX, обучение, независимые ревизии, переименование, границы удаления, сравнение нескольких снимков.
- `dotnet run --project tests/NGraph.UI.Tests -c Release` (Windows): реальные WPF окна и ресурсы без Revit API, меню, сравнение, фильтры, поиск справки и наличие встроенного PDF.
- В каталоге `build`: `dotnet run -c Release -- pack` — Release.R21–R27 и оба MSI.

Проверка в установленном Revit остаётся отдельным этапом: открыть настройки на реальном RVT, выбрать типы/параметры и запустить команды ФСА; проверить установку MSI под обычным пользователем и обновление поверх его INI. Автоматические проверки без Revit не подтверждают поведение семейств и транзакций в конкретном проекте.
